# ActualChat：AI 应用、Agent 与 Workflow 学习计划

版本：2。日期：2026-10-20。状态：用户已批准实施；同步目标随后更正为 `origin`。

## 目标与学习顺序

以 AI 产品开发为主线，结合 AI 编程协作流程，用中文讲解实际源码、架构和设计取舍。

1. **架构地图**：客户端、API 权限层、业务服务、数据库、事件与 Fusion。
2. **最小 AI 调用链**：从 `ConversationSummarizer` 理解输入整理、Prompt、模型调用、输出解析。
3. **持久化 Workflow**：从 `LiveConversationSummaryFlow` 研究状态、调度、重试和恢复。
4. **Agent 与 MCP**：研究工具接口、身份认证与权限边界，验证仓库是否存在自主 Agent 决策循环。
5. **工程实践**：分析限流、取消、错误处理、可观测性、输出验证和测试，并与官方资料交叉核对。
6. **AI 编程协作**：研究 AGENTS.md、Skills、代码审查及验证流程。

每一课包含源码位置、调用链、核心概念、设计取舍和理解检查题。先研究聊天摘要，再逐步扩展；音视频编解码和移动端构建暂不作为入门重点。

## Reuse：复用现有设计

优先研究和复用 `IConversationSummarizer`、`IChatDialogFormatter`、`RateLimitedChatCompletionService`、`Flow`、`FlowHub` 和 `FlowInbox`。

当前主要产出学习文档，不新增产品接口。后续若实施练习，先查类型索引；通用组件比较放入 `Core` / `Core.Server` 与功能模块的适用性，避免重复建设。
